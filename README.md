# Driver Saathi (Phase 1)

Hindi voice copilot for ride-app drivers. Phase 1: read ride/chat notifications aloud, take a spoken reply,
write it as a DRAFT in the chat box. The driver always presses Send/Accept/Reject.

Open this folder in Android Studio, or build with GitHub Actions (see build.yml). Debug APK output:
app/build/outputs/apk/debug/app-debug.apk

Next: floating bubble, Gemini replies (through your own server), Supabase login/earnings, subscription.
